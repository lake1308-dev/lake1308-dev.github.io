## 공식 데이터 원칙

공식 영양정보는 K-FIND/식품안전나라 자료를 우선 사용한다.

verified 등록 전 반드시 다음을 확인한다.

1. 식품명이 우리가 등록하려는 재료와 정확히 일치하는가
2. 생것/삶은 것/찐 것/구운 것 등 조리상태가 정확한가
3. 육류는 부위, 축종, 필요한 경우 등급을 구분했는가
4. K-FIND 원본 식품코드(`source_food_code`)를 저장했는가
5. 100g 기준인지 확인했는가
6. 출처 URL을 저장했는가
7. 공식 원본과 정확히 매칭되지 않으면 억지로 verified 처리하지 않는다

제품형 두부, 조리음식, 특정 가공제품 등을 일반 원재료 대표값으로 잘못 연결하지 않는다.

## 중요 운영 원칙

- 완벽한 250종을 기다리다가 공개를 늦추지 않는다.
- 핵심 식재료의 정확도를 확보하면 베타를 공개하고 실제 검색 데이터를 통해 확장한다.
- 숫자를 빨리 늘리기 위해 애매한 식품을 공식값으로 등록하지 않는다.
- 기존 verified 레코드는 새 작업 시 삭제하거나 덮어쓰지 않는다.
- `nutrition-kfind.json` 수정 전 항상 최신 파일을 다시 읽고 현재 SHA를 사용한다.
